## 三、R-1 改密提醒功能（本轮交付，v4.1.0）

| 环节 | 行为 |
| --- | --- |
| 登录时 | 密码仍是初始密码（工号）→ 自动投递一条站内信「安全提醒：请修改初始密码」，右上角铃铛角标出现；已有未读同类提醒不重复投，已读但没改下次登录再提醒 |
| 进入系统 | **弹窗强提醒**（⚠️ 盾牌图标）：立即修改 / 稍后再说；本次会话关掉不再弹，改掉之前每次登录都会再弹 |
| 通知页 | 该类提醒用警示色+盾牌图标区别于普通通知 |
| 改密成功 | 弹窗消失 + 标记刷新 + **铃铛角标即时归零**（自动把未读提醒置已读）+ 以后登录不再投递 |
| 主管重置密码后 | 该账号下次登录同样适用以上逻辑（重置的密码非工号即视为已改） |
