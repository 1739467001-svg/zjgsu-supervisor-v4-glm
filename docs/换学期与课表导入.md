# 换学期操作手册（现行版 v4.2.4 · 2026-11-06 第 20 轮换学期演练后重写）

> 本手册替代旧版脚本式流程（`import-courses.ts` 命令行导入已是历史，旧版全文见 git 历史）。现行系统从 v4.0.0 起为多学期档案 + 界面双入口两段式导入，全部操作在浏览器完成。
> 流程已于 2026-11-06 在生产快照副本上**完整演练通过**（演练报告见 `测试报告-2026-11-06-20.md`）。

## 一、核心原则：归档，不清空

换学期**不删除任何历史数据**。课程表按 `semesterId` 归档：旧学期课程、评价、听课计划原样保留、只读可查；新学期从空开始。系统里三道防线会拦住最常见的错误操作：

| 守卫 | 拦什么 | 表现 |
| --- | --- | --- |
| ① 激活守卫 | 误把历史学期「设为当前」（向后切换） | 报错「历史学期请使用查看学期入口，不可重新启用并修改档案」 |
| ② 文件学期守卫 | 课表文件里写的学年学期与目标学期不一致（如拿第一学期文件传给第二学期） | 预览即拒绝：「课表所属学期与当前学期不一致，已停止，未修改任何数据」 |
| ③ 两段式预览 | 旧文件覆盖新课表导致课程回退/删除 | 预览逐项列出「新增/更新/删除/保留」计数，**确认前不写任何数据** |

## 二、操作前准备

1. **先备份**：管理员执行 `bash /srv/apps/zjgsu-supervisor/backup.sh`（或等当日 03:00 自动备份后操作）。
2. **拿到真实的新学期课表文件**（两份）：
   - 《XX学年第二学期研究生排课信息表（不含 MBA）》——研究生院标准版
   - 《MBA XX 学年（二）学期课表》——MBA 中心版
   - ⚠️ 上学期的旧文件**用不了**：守卫②会按文件内标注的学年学期拒绝（这是故意的，防止旧课表覆盖新课表）。文件没到手不要开始本流程。
3. **跟研究生院确认两个参数**（整个流程最关键的输入，错一周全学期周次错一周）：
   - 第一周周一的日期（如 2027-03-08）
   - 总教学周数（如 18 周）

## 三、操作步骤（研究生院主管，浏览器内完成）

全程建议在夜间/无课时段操作：第 2 步激活后到第 3 步上传完成之间，全校课程列表短暂为空（新学期还没有课表）。

### 第 1 步：新建学期（不激活）
登录 → 左侧菜单「上传课程数据」→ 页面顶部「**学期配置**」面板 → 「**新建学期**」：
- 学年：`2026-2027`；学期名称：`第二学期`
- 第一周开始日期：按校历填（周一）
- 总周数：按校历填
- 创建。**新学期此时未启用**，不影响正在进行的任何功能。

### 第 2 步：设为当前
在「学期配置」面板找到新学期那一行 → 「**设为当前**」。
- 系统自动把顶部学期选择器切到新学期，并提示可直接上传；
- 旧学期自动变为「历史档案」，其课程/评价/计划全部原样保留、只读。

### 第 3 步：上传总课表（两段式）
同页「① 选择导入入口」→「**全校研究生总课表**」→ 选文件 → 「**解析预览（不写入数据）**」→ **逐项核对预览**：
- 识别格式与目标学期（应显示新学期名称）；
- 「预计新增」应约等于新课表门数（新学期为空，全部是新增；「预计更新/删除」应为 0）；
- 学院分布、警告列表（个别解析不出周次的课会提示）；
- 无误后「**确认导入以上数据**」。

### 第 4 步：上传 MBA 课表（两段式）
同页选「**MBA 课表**」入口 → 重复第 3 步（预览 → 确认）。

### 第 5 步：核对清单（照做，全过即完成）

| # | 核对项 | 预期 |
| --- | --- | --- |
| 1 | 学期配置面板 | 新学期带「当前学期」徽标，旧学期为普通行 |
| 2 | 顶部学期选择器 | 新学期标「当前学期」，上学期标「历史档案」 |
| 3 | 左侧菜单「全校课程」 | 只显示新学期课程，门数与课表一致 |
| 4 | 统计仪表盘 | 新学期口径：课程数=课表门数、评价 0 |
| 5 | 查看学期切到上一学期 | 历史课程/评价/计划原样可查（只读） |
| 6 | 督导建听课计划 | 只能选新学期课程；选旧学期课程会被拒绝 |
| 7 | 评价表单可选听课日期 | 落在新学期起始日前一周至学期末；旧日期被拒绝 |
| 8 | 定时任务 | 次日 00:30 起按新学期周次运转（可在 docker 日志确认） |

## 四、常见问题

- **预览提示「课表所属学期与当前学期不一致」**：拿错文件了（见守卫②）。向研究生院索取对应学期的新文件。
- **预览显示「删除 XXX 门」很多**：说明这份文件不是当前学期的新版课表（旧文件回退风险）。**不要确认**，核对文件版本。
- **个别课「解析不出周次」**：课表里该行周次列格式异常。导入后这些课在周次筛选里看不到，可让研究生院补正后重传（重传只影响差异行）。
- **激活错了想退回**：激活守卫①会拒绝向后激活。误激活新学期且还没上传课表的，联系管理员处理（涉及数据库操作，不要自行改库）。
- **导入后发现文件本身有错**：直接用更正版文件重传一次（同入口两段式，差异行会被更新，不影响已有评价/计划引用的课）。
