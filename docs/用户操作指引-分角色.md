# 督导系统分角色使用指引

依据：上线前需求对齐会议（2026-09）"各角色配备简易使用说明，包括功能指引和操作路径"。详细权限边界见 [角色与权限清单](./角色与权限清单.md)。

系统地址：由研究生院通知（校内虚拟机域名部署后更新至此）。

## 通用操作（所有角色）

1. **登录**：输入工号与密码（初始密码 = 工号），首次登录后请在左下角用户菜单 → 修改密码。
2. **切换学期**：页面顶部"查看学期"下拉框，选择如 `2026-2027-1 · 当前学期` 或 `2025-2026-2 · 历史档案`。历史学期只读，可查可导出，不能修改。
3. **切换身份**（仅双身份人员可见）：左下角用户卡片 → "切换身份"。切换只改变工作台视图，左侧菜单始终展示你被授权的全部功能。
4. **通知**：右上角铃铛；听课前一天系统会自动发送站内提醒。

## 研究生院主管 / 系统管理员

| 事项 | 操作路径 |
| --- | --- |
| 查看全校课程 | 侧边栏"全校课程"，可按学院/校区/周次/教师筛选 |
| 本人听课计划与评价 | "听课计划"选课建计划；听课后从计划或课程进入评价表填写，支持草稿自动保存 |
| 查看全部评价 | "全部评价"→ 查看/修改/导出 Excel、打印 PDF |
| 全校统计 | "统计仪表盘"（覆盖率、评价次数、平均评分三图 + 学院明细） |
| 评价进度 | "评价进度"按学院查看课程覆盖明细 |
| 用户与角色管理 | "用户管理"→ 搜索用户 → 改主角色/附加角色/学院/督导范围；页面下方可见授权变更留痕 |
| 上传课表 | "上传课程数据"→ 选择"全校研究生总课表"或"MBA 课表"入口 → 选文件 → 解析预览核对 → 确认导入 |
| 学期管理 | 学期切换下拉旁"学期设置"：新建学期、设置当前学期（仅主管） |

## 校级督导老师

| 事项 | 操作路径 |
| --- | --- |
| 查询全校课程 | "全校课程"，按学院/校区/周次筛选 |
| 制定听课计划 | "听课计划"→ 浏览课程 → 加入计划（选周次）；日历视图总览 |
| 听课评分 | 听课后进入"评价记录"或从计划进入评价表；20 项定量 + 亮点与建议，每 30 秒自动存草稿 |
| 提交/修改 | 必填项完整后"提交评价"；提交后如需修改在"评价记录"中编辑 |
| 查看本人评价 | "评价记录"→ 查看（本人记录可导出、打印） |

## 院级督导老师

同校级督导，但课程列表与评价范围限定在所属学院。其余操作路径完全相同。

## 学院教学秘书

| 事项 | 操作路径 |
| --- | --- |
| 查询本院课程 | "全校课程"（自动限定本院） |
| 查看本院全部评价 | "督导评价"→ 查看/导出/打印（只读，不能评分） |
| 本院评价进度 | "评价进度"→ 已评价/全部课程，点击课程看评价明细 |
| 本院统计 | "统计仪表盘"（学院统计仪表盘，全院口径：本院课程总数、覆盖率、评价次数、平均分） |

## 学院分管领导（双身份）

- 拥有本院督导 + 学院管理的全部功能：听课计划、评分提交（督导视图）与本院评价查看导出（管理视图）。
- 左下角可在"督导专家（院级）"与"学院管理"两个工作台间切换；无论在哪个视图，左侧菜单功能齐全。
- "统计仪表盘"为本院（全院）口径，不含其他学院。

## 常见问题

- **登录提示密码错误**：初始密码为工号；忘记密码请联系研究生院主管重置。
- **看不到某学院课程**：院级账号的范围由管理员配置的"所属学院 + 督导范围"决定，如不符请联系研究生院主管在"用户管理"中调整。
- **评价表提交不了**：检查必填项（二、三部分文本）；定量评分项均可选填，综合分自动计算。
- **课程已被评价**：一门课程只能有一条已提交评价；如需调整请联系研究生院主管。
- **上传课表提示"入口与文件模板不符"**：总课表请走"全校研究生总课表"入口，MBA 课表请走"MBA 课表"入口；两份文件分别上传互不影响。
